## Diagramme de classes – Itération 2

Dans cette étape, j'ai travaillé sur la réalisation du diagramme de classes de l'application TransLogix.

Le diagramme présente les principales classes métier du système, notamment :

- Utilisateur
- Employe
- Vehicule
- Client
- Mission
- Facture

Il présente également les relations entre les différentes classes ainsi que les énumérations utilisées pour gérer les statuts.

## Objectif

L'objectif est de représenter la structure statique de l'application et de faciliter la compréhension des relations entre les différentes entités.
